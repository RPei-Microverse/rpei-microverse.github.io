# Ruizhe Pei — personal website

Source for my academic website, a single hand-written page (`index.html`) served by GitHub Pages. There is no build step: edit `index.html`, commit to `main`, and the site updates within a few minutes.

The animation in the Research section (assets/aggregates.js) is a purely illustrative painting of bacteria gathering into a granule and loosening again; it does not depict real organisms. The paper texture and the wash in the footer and behind the portrait come from my watercolor microbe illustration.

When a custom domain is set up, add a `CNAME` file containing the domain and point the domain's DNS at GitHub Pages.
